01 System Architecture & Introduction to JRFK.exe

The JRFK 32-to-64-Bit Migration & Diagnostic Suite provides a comprehensive, zero-risk upgrade path for RF-KIT RF2K-S and RF2K+ linear power amplifiers. Over years of broadcast, DX, and contest operation, legacy 32-bit Raspberry Pi operating systems suffer from lack of upstream security patches, driver deprecation, and slow single-core telemetry polling. JRFK upgrades your amplifier to a high-performance, 64-bit Debian Trixie (aarch64) appliance while guaranteeing zero data loss and total preservation of all factory calibrations.

The Purpose of JRFK.exe

JRFK.exe is a dedicated, self-contained Windows utility engineered to safely transition your amplifier storage. It solves three critical operational challenges:

  • Golden Master Data Extraction: Safely mounts the 32-bit ext4 Linux filesystem on Windows in strict read-only mode, validating station callsign, Wi-Fi credentials, ATU relay solutions, and detector null calibration offsets before anything is altered.
  • Turnkey 64-Bit Provisioning: Wipes and partitions target high-endurance MicroSD media, writes the verified ~6.28 GB 64-bit Debian Trixie operating system image, and injects all preserved station parameters into the exact target paths required for plug-and-play operation.
  • System Recovery & Cloning: Provides the software engine to generate redundant field spares, rebuild lost media from scratch, and create verified backups without needing complex Linux commands.

The Dual-Architecture Model: Strict PC vs. Amplifier Separation

To eliminate operational confusion, the JRFK ecosystem is split into two completely separate, decoupled components that run on different hardware hosts:

03 Connecting to the Port 8088 Web Suite

The 64-bit appliance runs an embedded, asynchronous Python web server (rfk_tools_suite) listening on TCP port 8088. This diagnostic console is completely standalone from the RF-KIT touch GUI, allowing simultaneous local touchscreen control and remote browser monitoring.

Network Address Resolution

To connect from any device in your shack (desktop PC, laptop, iPad, or Android phone):

  1. By IP Address: If your router assigns the amplifier IP 192.168.1.150, enter:
    http://192.168.1.150:8088/
  2. By mDNS Hostname: The appliance broadcasts its hostname via Zeroconf/Avahi. If your station callsign is configured as k7bit, enter:
    http://k7bit.local:8088/
Browser Compatibility: The Port 8088 suite is fully responsive and rendered in classic Blueprint technical styling. It is tested and verified on Google Chrome, Mozilla Firefox, Apple Safari (iOS/macOS), and Microsoft Edge. No browser plugins or extensions are required.

04 Exhaustive Walkthrough of the 7 Blueprint Screens

The top navigation header provides instant, one-click access across all seven operational screens. Below is the complete operating guide for each screen:

1. 📖 Station Documentation Library (/docs)

Purpose: Serves as the central technical reference repository for the amplifier station, hosting four complete, publication-grade manuals in both interactive HTML and downloadable PDF formats.

How to Read It: The screen displays four unified document cards across the top and an embedded high-resolution reading frame below. The active document is highlighted with a green border and labeled in the reader toolbar.

How to Use It:

  • Click 📖 View Document on any card to load that manual directly into the embedded viewport.
  • Click ⬇️ Download PDF to download or open the print-ready, vectorized PDF file with zero formatting defects.
  • Use the toolbar controls: 🔄 Reload refreshes the document; 🌐 Open Full Window expands the document into a dedicated browser tab; 🖨️ Print Document initiates direct local printing formatted cleanly without web navigation elements.

2. 🗺️ Antenna Matrix Mapper & Tuner Bode Plot (/antenna)

Purpose: Visualizes the amplifier's 4-port coaxial antenna relay matrix, active band selection, and per-band automatic tuner (ATU) LC solutions in real time.

How to Read It:

  • 4 Coaxial Port Cards: Displays ANT 1, ANT 2, ANT 3, and ANT 4. The physically energized RF relay glows in vivid green with ● ACTIVE RELAY. Standby ports remain in muted blueprint blue with STANDBY. Custom labels configured in config.json (e.g., "160M INVERTED L", "STEPPIR 20-6M") appear directly on the cards.
  • Band Ribbon: An interactive ribbon displaying all supported amateur bands (160m, 80m, 60m, 40m, 30m, 20m, 17m, 15m, 12m, 10m, 6m).
  • Interactive Tuner Bode Plot: Graphs the calculated SWR curve across the band. Frequency segment boundaries are clearly indicated with vertical dividers (|).

How to Use It:

  • Telemetry Auto-Tracking: As you turn the transceiver VFO or switch bands via CAT, the antenna mapper automatically tracks the frequency, updating the active antenna card and tuning curve without user interaction.
  • Component Inspection: Click on any band or segment boundary to inspect the exact physical LC network solution: Inductance (L in nanohenries / nH or microhenries / µH) and Capacitance (C in picofarads / pF). This allows rapid verification that the internal ATU relays are latching to the correct values.

3. 📈 Amplifier Health Monitor & 60°C Thermal Guard (/health)

Purpose: Continuous, high-precision monitoring of the amplifier's electrical operating points and heatsink thermal dissipation to protect the push-pull Ampleon BLF189 / BLF189XR LDMOS transistors.

How to Read It:

  • 5 Real-Time Telemetry Gauges:
    1. Heatsink Temperature: Current PA copper heat-spreader temperature in °C.
    2. Forward Output Power: Real-time RF power delivery in Watts (0 to 2000 W).
    3. Reflected Power & SWR: Return loss and antenna SWR ratio (1.0:1 to 5.0:1).
    4. 53.5V DC Rail Voltage: Heiwoo main power supply rail voltage under static and key-down conditions.
    5. Drain Current (Id): Total PA drain current in Amperes (0 to 55 A).
  • 3 Real-Time Canvas Trend Charts: Continuously graph 15-minute rolling windows of Temperature trend, RF envelope power, and DC voltage sag during transmissions.

Multi-Tier Thermal Safety Guard:

  • Nominal State (≤ 50°C): Normal operation. High-efficiency chassis cooling fans engage automatically above 42°C.
  • Warning State (> 50°C): Visual banner warning indicating heavy contest duty cycle.
  • Red Alert State (> 55°C): Critical warning indicating heatsink is approaching maximum thermal dissipation limits.
  • Emergency Thermal Trip (> 60°C): Automatic unkey protection! The health engine immediately transmits an autonomous SimpleRPC command to switch the amplifier into Standby mode, dropping PTT. An emergency modal dialog locks the web screen, initiates a 300-second live cooldown countdown, and strictly locks out re-enabling until the heatsink cools below 50.0°C.

4. 📺 Remote Screen Mirror (/screen)

Purpose: Delivers a real-time, low-latency, pixel-accurate stream of the physical 1024x600 front-panel touchscreen display to any remote browser.

How to Read It: Exactly reproduces the front-panel cross-pointer meters, bar graphs, operating frequency, and amplifier status annunciators (OPERATE / STANDBY, BAND, ANT).

How to Use It:

  • Operates via the Raspberry Pi's secondary Full KMS DRM display pipeline, capturing frames directly from the frame buffer without loading the CPU.
  • Strictly Read-Only: Touch events and mouse clicks are deliberately disabled on the remote mirror. This guarantees that an accidental brush of a tablet or smartphone in the shack cannot alter amplifier settings, trip relays, or inadvertently key the amplifier.
  • Prop up an iPad or phone next to your logging computer or SDR console for instantaneous, heads-up status verification.

5. 💾 Disaster Recovery & SD Backup Manager (/backup)

Purpose: Manages raw, byte-level binary cloning of the active production MicroSD storage to provide instant failover in the event of storage failure.

How to Read It: Displays primary storage health, secondary backup target device (/dev/sda, labeled BACKUP-AUTO in the rear USB reader), last completed backup timestamp, compressed image size, and cron scheduling status.

How to Use It:

  • On-Demand Instant Cloning: Click ⚡ Run Full SD Backup Now before performing any station reconfigurations, firmware updates, or Shack electrical work.
  • Automated Weekly Cron: Runs autonomously every Sunday morning at 04:00 GMT, writing a compressed dd | xz raw disk image to /home/pi/backups/.
  • Emergency Hot-Swap: In the event of primary MicroSD failure during a contest, remove the card from the rear USB reader, insert it directly into the Raspberry Pi internal slot, and power on. Recovery takes under 3 minutes!

⚙️ Automated RPi OS Autopatching (Sunday Cron Engine)

Purpose: Keeps the Debian 13 Trixie 64-bit operating system, kernel security patches, hardware drivers, and network protocols fully up to date without manual sysadmin work.

How It Operates:

  • Immediately after the weekly binary raw image backup completes on Sunday at 04:00 GMT, the system executes:
    sudo apt update && sudo apt upgrade -y
  • Bulletproof Fail-Safe: Because a verified raw disk image was created minutes prior to executing apt upgrade, you are permanently protected against upstream Debian regressions. If an update ever creates an anomaly, you can immediately restore the Sunday pre-upgrade image.

Before beginning the migration, ensure your amplifier firmware meets the minimum standard and prepare your MicroSD media fleet.

FIRMWARE PREREQUISITE: Your RF-KIT amplifier must run firmware version v199, v200, or later prior to starting the migration. Internal controller parameter schemas were updated in v199 to support 64-bit SimpleRPC protocol parity.

06 The Golden Rule of Safety: Creating GOLD1 & GOLD2

Before writing a single byte of 64-bit software, you will clone your existing 32-bit working system into two physical Golden Masters directly on the Raspberry Pi using the desktop SD Card Copier tool (piclone):

  1. Boot the amplifier normally into your 32-bit system. Plug a blank 32GB MicroSD card into a USB reader connected to the Raspberry Pi.
  2. Open the Raspberry Pi desktop menu → Accessories → SD Card Copier.
  3. Select Copy From Device: Internal SD Card (/dev/mmcblk0).
  4. Select Copy To Device: USB Card Reader (/dev/sda).
  5. Click Start. Once complete, remove the card and label it GOLD1.
  6. Repeat this exact procedure with a second blank card and label it GOLD2.
ZERO RISK GUARANTEED: You now possess two independent, bootable, exact physical copies of your factory 32-bit system. Even in the worst-case scenario, re-inserting GOLD1 returns your amplifier to 100% factory operation in under 60 seconds.

07 Option 1: 64-Bit OS Migration with JRFK.exe

With GOLD1 created, you can now generate your production 64-bit SD card (PROD-64) using the Windows PC utility:

STEP 1 Launch JRFK.exe on Windows

Connect your USB MicroSD reader to your Windows PC with GOLD1 inserted. Launch JRFK.exe. Accept the Windows UAC Administrator prompt. The tool will automatically open your default browser to http://127.0.0.1:8089/.

STEP 2 Read-Only GOLD Asset Extraction

Click 1. Validate & Extract GOLD SD. JRFK reads the Linux ext4 rootfs in strict read-only mode, validating your callsign, Wi-Fi SSID, calibration files, and tuning tables. It computes SHA-256 signatures to confirm data integrity.

STEP 3 Swap to Target Blank SD Card

Eject GOLD1 and safely store it in your shack vault. Insert a fresh blank 32GB card (labeled PROD-64). Click Rescan Disks and select the target drive.

STEP 4 Write 64-Bit Image & Inject Factory Calibrations

Click 2. Provision SD (Migrate to 64-Bit). JRFK wipes the card, flashes the verified 64-bit Debian Trixie image (~6.28 GB), and injects all your preserved calibrations, Wi-Fi network credentials, headless SSH keys, and custom 1024x600 display modelines.

08 The 3-Boot Walkthrough: From Automation to Production

Insert the newly created PROD-64 card into your amplifier's Raspberry Pi and power on. The amplifier will perform an automated 3-boot initialization:

  • Boot 1 (Partition Expansion & Offline Debs): The system auto-expands the Linux rootfs to utilize the full 32GB card, unpacks the 15 offline Debian packages, installs Python 3.13 shims, and reboots automatically (~90 seconds).
  • Boot 2 (Hardware Link & Controller Handshake): The system tests the USB serial link to the Arduino / proprietary controller (/dev/ttyUSB_RFK). Once verified, it displays a green completion confirmation and reboots into production mode.
  • Boot 3 (Production Mode): Boots directly into the fullscreen 1024x600 RF-KIT touchscreen GUI. The Linux desktop is completely hidden. All RF-KIT meters, antenna ports, and menus are live.

09 Option 2: Virgin Fresh 64-Bit Setup (Without GOLD Card)

If your original 32-bit SD card was lost or corrupted, JRFK allows building a complete, clean 64-bit OS from scratch:

  1. Open JRFK.exe and navigate to Option 2: Fresh Setup.
  2. Enter your Callsign, Shack Wi-Fi SSID and Password, and select your transceiver CAT rig.
  3. Click Build Fresh 64-Bit SD. JRFK generates a turnkey 64-bit image populated with standard K7BIT cookbook tuning profiles ready for on-air alignment.

10 Emergency Disaster Recovery & Field Hot-Swap

If your primary production SD card ever experiences hardware degradation or read errors during a contest:

THE 3-MINUTE RECOVERY PROCEDURE:
  1. Switch AC mains power to OFF. Disconnect AC power cord. Wait 30 seconds for power supply capacitors to bleed down.
  2. Press and remove the degraded card from the internal Raspberry Pi slot.
  3. Insert your BACKUP-AUTO card (from the rear USB reader) or your pre-provisioned FIELD-64 card into the internal slot.
  4. Reconnect AC power and switch power to ON. The amplifier boots immediately into full operation with all calibrations intact.
