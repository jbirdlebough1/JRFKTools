Disaster Recovery Walkthrough

  • 1
    Swap SD Cards: In the event of primary boot SD failure, power off the amplifier and remove the internal SD card from the Raspberry Pi slot. Remove the cloned backup SD card from the external USB reader and insert it directly into the Raspberry Pi internal slot.
  • 2
    Power On & Automated First Boot: Turn on amplifier main power. The built-in jrfk_restore_check service automatically verifies user files, aligns partition UUIDs, logs restoration, and executes a single clean reboot.
  • 3
    Immediate Resumption: Following the automatic reboot, the system launches directly into the fullscreen RFKGUI touch interface with 100% of your antenna memory maps, calibration potentiometers, and operational logs completely intact!
