What’s New in Beta 1.0:

1. Automated 32-Bit to 64-Bit Raspberry Pi OS Migration:
   * Migrates legacy 32-bit Raspberry Pi OS installs to pure 64-bit Raspberry Pi OS on kernel 6.12 with Full KMS direct rendering and Simple RPC controller communication.
   * Option A (Gold to Production): Extracts 100% of calibration files, directional coupler nulls, ADC lookup tables, and station Wi-Fi from your existing working SD card.
   * Option B (Clean Install to Production): Directly provisions a fresh target card with station credentials.
   * Verified Two-Boot deployment process: Automated root partition expansion on Boot 1, production service on Boot 2.

2. On-Amplifier JRFK Web Tools Suite (Port 8088):
   * Concurrently served directly by the amplifier on port 8088 alongside the native front-panel GUI.
   * Health Guard: Real-time Peak Envelope Power metering (up to 1500W), reflected power, 53.5V rail monitoring, and 60°C thermal safety protection.
   * Remote Screen Viewer: Network HDMI extension providing a live, real-time 1024x600 framebuffer mirror. Crucially, this interface is strictly READ-ONLY for safe visual observation without accidental touch trips.
   * Antenna Matrix & B26-ATU: Automatic CAT-controlled 4-way antenna port selection, switched relay/PIN-diode component engagement, and real-time SWR Bode plot.
   * SD Backup Manager & Disaster Recovery: Plug an inexpensive USB SD card reader with a spare card into the amplifier to clone your active system in 15 minutes while remaining on the air. Configured with a scheduled background cron job for automated system updates, upgrades, and standby backups.
   * Diagnostic Event Logs: Centralized millisecond-timestamped terminal tracking GUI events, Simple RPC transactions, and fault alerts.
   * Integrated Documentation Portal: Offline technical manuals, build documentation, and B26 operating guides served locally on port 8088.

3. Station Reference Library & Manuals:
   * The complete reference manual for builders and operators, complete with full circuit board layouts, photos, and calibration procedures.
   * Complete 4-volume documentation library available offline on the amplifier and online via GitHub Pages.
